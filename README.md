# Картирование металлического снега на Венере с проверкой бистатическим радаром и 2.5D-визуализацией
### Интерактивный 3D-атлас металлического снега и морфометрии Венеры

> **Проект:** Исследование радиофизических аномалий высокогорий Венеры по данным КА «Магеллан» (NASA PDS Geosciences Node) и моделей машинного обучения (ML HistGB + KMeans).  
> **Автор исследования и визуализации:** Vasily Guryanov  
> **Стек:** Three.js (WebGL), Python 3 (Backend HTTP/Range server), glTF 2.0 / Wavefront OBJ.

---

## Быстрый запуск

Сайт запускается одной стандартной командой без необходимости установки сторонних библиотек:

```bash
# Вариант 1 (прямой запуск через Python 3):
python3 app.py

# Вариант 2 (через скрипт):
./run.sh
```

Для остановки сервера в терминале нажмите **Ctrl+C** (или **Command+C**).

После запуска перейдите в браузере по адресу:
**http://localhost:8000**

*(Если порт 8000 занят другой программой, сервер автоматически подберет свободный порт 8001, 8002 и т.д. и выведет точную ссылку в терминал).*

Для автоматического открытия браузера при старте:
```bash
python3 app.py --open
```

## Основные возможности

### 1. 3D-модели Венеры и ключевых высокогорных регионов
- **Венера (Глобальный глобус)**: Единичная сфера (R = 6051 км), вертикальное преувеличение рельефа x40, 259 560 вершин, 516 960 полигонов.
- **Горы Максвелла (Maxwell Montes)**: Высочайший массив планеты (11.29 км), снеговая линия h_c = 5.51 км, 52.7% площади под металлическим снегом.
- **Область Овда (Ovda Regio)**: Крупнейшее экваториальное плато Земли Афродиты, h_c = 3.88 км, площадь снега 4.49 млн км^2.
- **Область Тетис (Thetis Regio)**: Восточное плато Земли Афродиты, h_c = 3.76 км, площадь снега 3.10 млн км^2.
- **Область Бета (Beta Regio)**: Вулканический щит с рифтовой зоной Девана, h_c = 4.26 км.
- **Область Атла (Маат) (Atla Regio / Maat Mons)**: Высочайший вулкан Венеры (9.66 км), h_c = 3.74 км.
- **Гора Гула (Gula Mons)**: Вулканический массив Западной Эйстлы (4.63 км), h_c = 3.78 км.

### 2. Мультиспектральные радарные слои данных
Все модели поддерживают мгновенное переключение текстурных карт без повторной загрузки 3D-сетки:
- **Высота рельефа (elev)**: Топографический градиент альтиметрии Magellan GTDR (от -1.1 до +11.3 км).
- **Вероятность «снега» (snow_prob)**: Карта предсказаний классификатора HistGB (ROC-AUC = 0.996, PR-AUC = 0.88).
- **Рельеф + Снежный покров (elev_snow)**: Композитная карта высот с акцентированным снежным покровом.
- **Типы поверхности (cluster)**: Кластеризация KMeans (k=3):
  1. *Гладкие низменные равнины* (82.9%)
  2. *Шероховатый рельеф (тессеры, рифты)* (15.2%)
  3. *Высокогорья с низкой излучат. способностью («металлический снег»)* (1.8%)
- **Аномальность (anomaly)**: Перцентиль аномальности EllipticEnvelope (0.5 - 1.0).
- **Излучательная способность (emis)**: Радиояркость Magellan GEDR (0.42 - 0.91).
- **Диэлектрическая проницаемость (eps_refl)**: Проницаемость eps (2.8 - 50.7).
- **Отражательная способность (refl_norm)**: Нормализованный радарный коэффициент Magellan GREDR.
- **RMS-уклон (slope)**: Шероховатость поверхности по закону Хагфорса Magellan GSDR (0.8 deg - 8.1 deg).

### 3. Тонкая настройка изображения и физических параметров (PBR)
- **Уровни снеговой линии**: Интерактивный регулятор порога вероятности P_snow с динамическим пересчетом площади покрова в км^2.
- **Режимы отображения**: Сплошной текстурированный, Наложение полигональной сетки (Wireframe Overlay), Чистая полигональная сетка, Облако точек (Point Cloud).
- **Материал**: Настройка шероховатости (Roughness), металличности (Metalness) и глубины рельефа (Bump scale).
- **Интерактивное Солнце**: Свободное вращение источника освещения по азимуту (0 - 360 град) и высоте над горизонтом (5 - 85 град) для выявления теней и морфологии кратеров и рифтов.
- **Пресеты освещения**: «Планета», «Студия», «Закат» и «Научный плоский».
- **Камера**: Переключение между 3D-перспективой и ортогональным видом сверху (план-карта), авто-вращение, сброс вида.
- **Бистатический радар (BSR)**: Отображение орбитальных пролетов КА «Магеллан» (орбиты 4156130b, 4156155b, 4156191b) с цветовой шкалой проводимости m_c.

### 4. Экспорт для будущего сайта на Three.js и 3D-пакетов
- **Скачать модель .GLB**: Прямой экспорт двоичного glTF 2.0.
- **Экспорт в Wavefront .OBJ + .MTL**: Клиентский конвертер с сохранением нормалей, геометрии и UV-развертки для Three.js, Blender, Maya.
- **Скачать активную текстуру (.PNG)**: Выгрузка текущего слоя карты.
- **Снимок экрана (.PNG)**: Рендер сцены в разрешении дисплея без интерфейсных элементов.
- **Скачать manifest.json**: Полная схема параметров, шкал и текстур.
- **Полный ZIP-архив**: Единый пакет моделей и текстур (85 МБ).

## Научный контекст

В высокогорьях Венеры (выше 3.7–5.5 км) температура падает ниже 380 °C, способствуя конденсации халькогенидов тяжелых металлов (теллур, висмут, сульфид висмута, галенит). Образующийся полупроводниковый слой приводит к резкому снижению излучательной способности (e < 0.5) и возрастанию диэлектрической проницаемости (eps > 30–50).
Атлас позволяет интерактивно исследовать пространственное распределение этого феномена.
